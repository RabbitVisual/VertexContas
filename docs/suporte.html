Manual do Agente de Suporte

Este manual descreve as funcionalidades do painel de suporte (PanelSuporte). Acesso para roles admin e support.

Visão Geral

O painel de suporte concentra tickets, Chat VIP, modo inspeção remota, Wiki interna e gestão de usuários (quando o usuário concede acesso de suporte). Todas as ações são registradas no Audit Log.

Tickets (Chamados)

Gerencie os chamados abertos pelos usuários. Responda mensagens, feche tickets e atribua a outros agentes. A partir de um ticket, você pode solicitar inspeção remota para visualizar a sessão do usuário e auxiliar na resolução do problema.

Chat VIP

Assinantes PRO têm acesso ao Chat VIP em tempo real. Atendimento direto via chat, transferência de conversas entre agentes e possibilidade de solicitar inspeção a partir do chat.

Modo Inspeção

O modo inspeção permite que o agente visualize a sessão do usuário como se estivesse logado em sua conta — útil para diagnosticar problemas de interface ou fluxo. O usuário precisa aceitar a solicitação de inspeção.

Privacidade e InspectionGuard

Durante a inspeção, o usuário pode optar por não mostrar dados financeiros. Quando essa opção está ativa:

  • Valores monetários são mascarados (ex.: R$ 00.000,00)
  • Gráficos são ofuscados (blur) e os dados não são enviados ao agente
  • Exportações de relatórios e extratos são bloqueadas
InspectionGuard

O serviço InspectionGuard centraliza a lógica de privacidade. Quando show_financial_data = false, todos os valores sensíveis são mascarados no servidor — os dados reais nunca chegam ao agente. Isso garante conformidade com a LGPD e proteção ao titular dos dados.

A inspeção tem tempo limite e pode ser encerrada a qualquer momento pelo agente ou pelo usuário.

Audit Log (SupportAuditLog)

Todas as ações relevantes dos agentes são registradas no SupportAuditLog, incluindo:

  • Início e término de inspeção
  • Alterações em usuários (edição, envio de reset de senha, logout forçado)
  • Importação de transações durante inspeção
  • Alterações em configurações do sistema (Admin)

O log permite auditoria e rastreabilidade em caso de reclamações ou exigências legais.

Wiki

A Wiki interna reúne artigos de conhecimento para a equipe de suporte. Consulte documentação, procedimentos e referência legal. Sugestões de novos artigos podem ser enviadas pelos agentes.

Gestão de Usuários

Quando o usuário concede acesso de suporte (em Segurança → Suporte), o agente pode:

  • Visualizar e editar dados cadastrais (com máscaras LGPD quando aplicável)
  • Enviar link de reset de senha
  • Forçar logout em todas as sessões do usuário
Dados sensíveis

Sempre utilize as máscaras LGPD (CPF, telefone) ao exibir dados de terceiros em contextos de suporte. O sistema aplica lgpd_mask_* automaticamente em diversos pontos.
